# Yt-video Frontend (UI only)

This repository branch `frontend/ui` contains a production-oriented frontend for a YouTube Video Downloader website. It is UI-only: no backend logic, no demo data, no fake history. All pages, components, and interactions are implemented for a real production integration.

Key features:
- React + Vite
- Responsive, accessible, mobile-first UI
- Dark mode & light mode with persistence
- Semantic HTML and keyboard navigation
- Complete pages: Home, Downloads, History, Settings, About, Contact
- Reusable component design system

To run locally:

1. npm install
2. npm run dev

Note: This is the frontend only. Video metadata fetching and downloading require a backend and are intentionally left out.
